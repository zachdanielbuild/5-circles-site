# 5 Circles of a Healthy Church

The website for the 5 Circles of a Healthy Church, an Antioch Movement resource.

- The site is plain HTML and CSS, with no build step.
- `index.html` is the homepage. Images live in `images/`.
- The master copy of all text lives in Notion, on the "5 Circles of a Healthy Church" page. Edit the text there, then update the site from it.
- Every push to `main` is published automatically by Cloudflare Pages.
